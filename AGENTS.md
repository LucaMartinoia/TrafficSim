# Instructions

When writing code, always add inline comments to highlight the various steps. Also, unless required by libraries API, do not use functionalities above C++ 17.

When asked to refactor something, keep comments as they are or rewrite comments of the same specificity as needed. Comments never end with a period.

Avoid lambdas when possible, prefer a small explicit helper function.

For future reference: this is NOT a production software or anything like that. The only goal of this project is for me to become a bit more comfortable with C++ and learn C++ and QML, while also developing something rather hard and hopefully fun/nice.
